Extra Credit Troubleshooting:

1. Ensure your recipe uses inherit module and ensure this is placed at the top of your recipe and before any FILES:${PN}.

2. Look for the hello-mod_0.1.bb file in the same poky branch as a working example.

3. If using modprobe to load the faulty driver, you need a config framework to prevent a conflict with the CONFIG_MD_FAULTY kernel built-in driver. You may notice a message ERROR: module faulty is builtin. when attempting to modprobe without this change

To resolve, you can either create a kernel config fragment with # CONFIG_MD_FAULTY is not set or use insmod instead of modprobe to load the faulty driver in your startup script.

4. If you define your own do_install function you must call module_do_install to do the module install portion.

5. It's easiest to have multiple recipes for scull and misc-modules. If you want to write a single recipe for both modules you'll need your own custom call to oe_runmake, you can leverage module_do_install in the poky repo and module.bbclass as an example.
