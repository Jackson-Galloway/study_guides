eBPF (suggested as a next topic to learn more about):

eBPF is a more general technology than just for networking, but since this is a networking course, it’d be a great place to start learning about it. The first resource is an academic paper and some tutorials. The second is resources from Brendan Gregg, who’s videos and writing I find to be very informative and detailed – it’s straddles the line of being simple to understand and yet incredibly deep, which is incredibly challenging to do.

The eXpress data path: fast programmable packet processing in the operating system kernel.CoNEXT 2018. (opens in a new tab, external link)

  • This was an academic paper that introduced XDP, which leverages eBPF and integrated into the Linux kernel.

  • You can then find tutorials on XDP: XDP Project (opens in a new tab, external link)
