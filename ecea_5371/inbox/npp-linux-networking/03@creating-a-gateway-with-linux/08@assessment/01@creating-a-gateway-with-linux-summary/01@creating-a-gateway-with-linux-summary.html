In a practice exercise, we ran a command, 'iptables -t nat -A PREROUTING -d 111.111.0.1 -p tcp --dport 1000 -j DNAT --to-destination 10.10.0.2'. What is this doing?

  • This is an illegal command and would not have any affect.

  • For ingress traffic destined to the public facing IP address of the gateway (111.111.0.1), it translates the destination to 10.10.0.2, a private IP address of an internal host.

  • For traffic coming from an internal host, with the address 10.10.10.2, translate the destination to the IP address of the public facing address, 111.111.0.2

  • For traffic that is marked to be translated (with the nat mark in the packet), translate destination to 10.10.0.2.
