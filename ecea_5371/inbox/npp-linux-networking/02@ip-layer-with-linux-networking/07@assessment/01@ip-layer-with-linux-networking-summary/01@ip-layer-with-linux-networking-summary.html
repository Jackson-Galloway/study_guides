What does via do in 'ip route add'? e.g., ip route add 11.11.0.0/16 via 192.168.2.1 dev eth3 vs ip route add 11.11.0.0/16 dev eth3.

  • Linux will ARP for the destination in the packet (without via), or ARP for the next hop (with via).

  • Linux will send the traffic through a network monitor in addition to sending it to its destination (with via), as opposed to just to the destination (without via)

  • Linux will send traffic through a GRE tunnel (with via) or directly to the destination (without via)
