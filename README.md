# Final Exam Study Materials — CU Boulder MS-ECE Embedded Linux Specialization

Each course folder has four files next to its `inbox/` download:

| File | What it is |
|---|---|
| `study-guide.md` | Full study guide covering every module (from all transcripts, slides, readings), with a **Cheat-Sheet Candidates** box per module and quick-reference tables at the end |
| `quiz-answer-key.md` | Answers + explanations for every course quiz (graded quizzes in 5305/5306; practice quizzes in 5307) |
| `practice-exam.md` | 50-question practice final in the same T/F, multiple-choice, select-all format as the real exam |
| `practice-exam-answers.md` | Answer key with explanations and links back to study-guide sections |

## Courses

| Course | Final exam | Folder |
|---|---|---|
| **ECEA 5305** Linux System Programming & Intro to Buildroot | 2 hours, 15% of grade | [`ecea_5305/`](ecea_5305/study-guide.md) |
| **ECEA 5306** Linux Kernel Programming & Intro to Yocto | 2 hours, 15% of grade | [`ecea_5306/`](ecea_5306/study-guide.md) |
| **ECEA 5307** Linux Embedded System Topics & Projects | 45 minutes, 5% of grade | [`ecea_5307/`](ecea_5307/study-guide.md) |

All three finals are proctored (ProctorU), one attempt, and allow **one notes sheet that must be your own**. Lecture slides, textbooks, and AI tools are not allowed during the exam.

## Suggested study plan (per course)
1. Read the study guide one module at a time.
2. Go through the quiz answer key; for any answer that surprises you, re-read that study-guide section.
3. Take the practice exam timed and closed-book (notes sheet only), then grade it with the answer key.
4. Write your own one-page notes sheet using the Cheat-Sheet Candidates boxes as a starting point.

## About the quiz answers
The Coursera download included the quiz questions but not their answers. The answers here were worked out from the lecture material, and ⚠️ marks the few where the question wording is ambiguous. The courses' "Full AI" policy allows AI tools on coursework **if you document their use**; it does not allow them on the final exam.
