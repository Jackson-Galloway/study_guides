# Final Exam Study Materials — CU Boulder MS-ECE

Each course folder holds the Coursera download in `inbox/` plus the study files described below.

## Network Systems courses (ECEA 5370 / 5371 / 5372)

| File | What it is |
|---|---|
| `study-guide.md` | Full study guide covering every module (from all transcripts, slides, readings and assigned papers), with a **Memorize** box per module, quick-reference tables, and a **graded quiz coverage map** at the end |
| `practice-exam.md` | Practice final in the real exam's format (multiple choice plus free response), with new questions written from the lectures |
| `practice-exam-answers.md` | Answer key with explanations, links back to study-guide sections, and sample free-response answers |

| Course | Final exam | Folder |
|---|---|---|
| **ECEA 5370** Network Systems Foundations | 2 hours, 34 questions, 1 attempt, 10% of grade | [`ecea_5370/`](ecea_5370/study-guide.md) |
| **ECEA 5371** Network Principles in Practice: Linux Networking | 2 hours, 22 questions, 1 attempt, 20% of grade | [`ecea_5371/`](ecea_5371/study-guide.md) |
| **ECEA 5372** Network Principles in Practice: Cloud Networking | 90 minutes, 34 questions, **2 attempts**, 15% of grade | [`ecea_5372/`](ecea_5372/study-guide.md) |

- **Exam rules:** all three finals are **unproctored**, multiple choice plus **one free-response** question, with **no notes or websites allowed**. Unlike the Embedded Linux finals, there's no notes sheet.
- **No quiz answer keys for these courses.** They use the **"Conditional AI"** policy. It allows AI for summaries and practice questions, but not for answering graded quizzes or labs, or for entering their questions into an AI tool. Every quiz in these courses is graded, so each study guide has a coverage map instead: it lists the sections each quiz draws on, without answering anything.

## Suggested study plan (per course)
1. Read the study guide one module at a time, before or alongside that module's quiz.
2. After a quiz is graded, compare Coursera's feedback with the matching study-guide sections.
3. Take the practice exam timed and closed-book, then grade it with the answer key.
4. Re-read the sections behind every missed question, and know the **Memorize** boxes cold.
