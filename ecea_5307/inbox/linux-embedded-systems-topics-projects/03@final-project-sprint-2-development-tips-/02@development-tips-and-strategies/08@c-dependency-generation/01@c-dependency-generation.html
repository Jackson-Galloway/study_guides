What is a reason to use automake for your project dependency generation instead of GNU Make?

  • Better support for Windows builds

  • Tighter integration with a GNU software defined workflow

  • Supports targeting more Linux based platforms

What are some benefits of using CMake for dependency generation when compared to GCC Make or Autotools/Automake?

  • Supports additional project output formats like visual studio projects and workspaces

  • Capable of generating GNU makefiles

  • Fewer configuration lines required for basic projects

  • Better support for building projects on Windows platforms.

  • Works with GCC compiler
