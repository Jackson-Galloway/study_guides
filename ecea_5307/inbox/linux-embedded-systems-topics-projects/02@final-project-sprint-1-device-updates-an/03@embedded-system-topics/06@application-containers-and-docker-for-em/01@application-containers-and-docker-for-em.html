What is one difference between a container and a virtual machine?

  • A virtulal machine does not have a dedicated root filesystem, shares the root filesystem with the host OS.

  • A container does not have a dedicated root filesystem, shares the root filesystem with the host OS.

  • A container does not have a dedicated kernel, shares the kernel with the host OS

  • A virtual machine does not have a dedicated kernel, shares the kernel with the host OS

How is the kernel namespace feature used to support application containers?

  • Enforce limits and constraints on process memory

  • Create a virtual isolated network instance used for the container

  • Combine multiple directories on the host into a single rootfs directory inside the container

How is the kernel control groups feature used to support application containers?

  • Create a virtual isolated list of process IDs used for the container

  • Enforce limits and constraints on process CPU

  • Combine multiple directories on the host into a single rootfs directory inside the container.

How is the kernel union mounts feature used to support application containers?

  • Enforce limits and constraints on process memory

  • Create virtual isolated ports used inside the container

  • Combine multiple directories on the host into a single rootfs directory inside the container.
