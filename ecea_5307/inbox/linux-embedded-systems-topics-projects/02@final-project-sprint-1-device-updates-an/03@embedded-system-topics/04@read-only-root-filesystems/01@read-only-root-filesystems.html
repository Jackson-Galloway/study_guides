Advantages of Read Only Root File Systems are:

  • Simplifies factory default reset strategies

  • Easier to setup

  • Easier to modify

  • Avoids unintentional writes

  • Reduces File System corruption possibilities

  • simplifies device update strategies

Use a tmpfs filesystem for

  • Content which can be lost after reboot

  • Content which needs to persist across reboot

  • Content which is saved to disk

  • Content which uses RAM space instead of disk space

What benefit does a read only root filesystem offer in an A/B update scenario?

  • Replaces the bootloader update scheme

  • Ensures modified content is not lost when switching boot partitions

  • Removes the need for additional data partition

Select options for implementing a read only root filesystem on embedded Linux based devices

  • Use OverlayFS to overlay the entire root filesystem with another partition

  • Use OverlayFS with upper layers on tmpfs or data partition

  • Ensure no linux applications need to write any content to the root filesystem

  • Use symbolic links to data partition or tmpfs for modified content
