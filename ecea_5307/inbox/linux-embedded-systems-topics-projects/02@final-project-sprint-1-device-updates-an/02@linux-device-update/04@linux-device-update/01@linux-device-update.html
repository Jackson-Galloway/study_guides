What is a reason to use A/B Dual Redundant updates instead of Single Copy or Application Update schemes?

  • Ability to roll back to a previous known good and unmodified root filesystem, even after upgrade failure.

  • Simplest implementation possible

  • Minimized storage space reuired for update
